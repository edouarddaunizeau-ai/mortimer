# Decide

1. Restate the decision in one line. If a key fact is missing and changes the answer, ask one question; otherwise make the assumption and say so.
2. Two to four real options, the criteria that matter, numbers where they exist (search the web for current prices or facts, cite sources).
3. One recommendation with the main reason and the main risk.
4. Phone card: the recommendation as the title, the top lines, chip WHY NOT B (send "Why not the second option?").
